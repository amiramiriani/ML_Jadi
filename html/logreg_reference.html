LogisticRegression — Solvers & Regularization

Quick reference for sklearn 1.8+ — penalty API, solvers, and C tuning

from sklearn.linear_model import LogisticRegression
Solvers
liblinear
Fast on small datasets. Only OvR for multiclass — not multinomial.
small data L1 L2
lbfgs
Sklearn default. Reliable all-rounder, handles multinomial natively. No L1.
small–med L2 None multinomial
saga
Most flexible. Supports every penalty type. Best for large datasets.
large data L1 L2 ElasticNet None multinomial
sag
Like saga but no L1 or ElasticNet. Faster than lbfgs on large data.
large data L2 None multinomial
newton-cg
Handles multinomial natively. Slower on large datasets — prefer lbfgs.
medium L2 None multinomial
newton-cholesky
Best when features >> samples. Binary classification or OvR only.
wide data L2 None
Regularization — L1 vs L2
L1
Lasso  ·  l1_ratio=1
Cuts weak features to exactly zero — automatic feature selection.
penalty = (1/C) · Σ |wᵢ|
Use when: many irrelevant features, high-dimensional data, you want a sparse model.
L2
Ridge  ·  l1_ratio=0 (default)
Shrinks all coefficients toward zero — no feature is ever fully removed.
penalty = (1/C) · Σ wᵢ²
Use when: all features contribute something, you want stable predictions, multicollinearity present.
C — Regularization strength
C is the inverse of regularization — smaller C = stronger penalty.
